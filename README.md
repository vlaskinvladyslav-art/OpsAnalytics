# OpsAnalytics PWA — Process Manager DEMO v3

Поточна демо-версія першого робочого простору керівника процесу **«Балансування»**.

## Що реалізовано

- Desktop: постійна бокова навігація.
- Mobile: фіксована нижня навігація з іконками; desktop-кнопка меню на телефоні прихована.
- Pinch-to-zoom вимкнений.
- Випуск за зміну з масштабованим списком 6-значних номерів замовлень.
- Окремі показники **4320**, **3115** та **R&D**.
- Для 4320/3115 показана фактична динаміка виробітку за останні дні.
- R&D показується як погодинна робота без лінійного графіка, оскільки це внутрішні переміщення/підстраховка з оплатою за час.
- Пошук конкретного замовлення за номером.
- Для знайденого замовлення: артикул, фактична кількість виробів, працівники, їх КПД та фактична динаміка випуску за днями.
- Рейтинг працівників у широких картках, щоб зменшити вертикальну прокрутку.
- У картці працівника видно до 5 замовлень одразу. Решта відкривається кнопкою з номером замовлення, кількістю виробів та артикулом.
- М'які анімації входу, переходів між вкладками та hover/focus-станів.
- Немає прокрутки всієї сторінки по горизонталі; внутрішній горизонтальний скрол може використовуватися лише для контенту, де це справді потрібно.
- Demo-auth зберігає вхід у `localStorage`, тому після перезапуску сторінки користувач не вилітає з демо-акаунта.
- Окрема кнопка виходу з акаунта доступна в desktop sidebar та в «Налаштуваннях».

## Firebase Rules

Актуальні правила Realtime Database збережені окремо у **firebase.rules.json**.

Вони обмежують доступ до `users/$uid`: користувач працює тільки зі своїм профілем/даними, а `vlaskin.vladyslav@gmail.com` має службовий доступ для адміністрування `profile` та обходу блокування.

Під час переходу з demo-auth на Firebase Auth для збереження сесії потрібно використовувати Firebase Auth persistence (`browserLocalPersistence`) перед `onAuthStateChanged`/логіном.
